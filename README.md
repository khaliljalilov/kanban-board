# 📋 Kanban Tapşırıq Lövhəsi

🔗 **[Canlı Demo](https://khaliljalilov.github.io/kanban-board)**

Vanilla JS ilə yazılmış, localStorage dəstəkli Kanban tapşırıq idarəetmə lövhəsi.

---

## 🚀 Özəlliklər

- ✅ JS massivindən dinamik render (DOM manipulyasiyası)
- ✅ Tapşırıq əlavə et / redaktə et / sil
- ✅ Sütunlar arası Drag and Drop (HTML5 API)
- ✅ localStorage ilə saxlama — səhifə yenilənəndə vəziyyət qorunur
- ✅ Açar söz və prioritet üzrə axtarış və filtrasiya
- ✅ XSS qorunması (`textContent` ilə)
- ✅ Təkrarlanan tapşırığın qarşısının alınması
- ✅ Responsiv dizayn (Mobile-first)

---

## 🛠️ Texnologiyalar

| Texnologiya | İstifadə |
|---|---|
| HTML5 | Semantik struktur |
| CSS3 | Flexbox, Grid, animasiyalar, CSS dəyişənləri |
| Vanilla JavaScript | DOM manipulyasiyası, event-lər, localStorage |
| HTML5 Drag and Drop API | Sütunlar arası sürükləmə |

---

## ⚙️ Quraşdırma

Heç bir quraşdırma tələb olunmur — xalis HTML/CSS/JS layihəsidir.

```bash
# Repo-nu klonla
git clone https://github.com/khaliljalilov/kanban-board.git

# Qovluğa gir
cd kanban-board

# index.html faylını brauzerdə aç
```

Və ya birbaşa [canlı demo](https://khaliljalilov.github.io/kanban-board) linkinə keç.
